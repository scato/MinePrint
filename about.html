About

This Minecraft blueprint viewer is a personal hobby project. It is intended primarily for personal use, but if other Minecraft players out there find it useful, that's fine by me. Just don't expect me to solve bugs or add new features.

Also, keep it civil. Mojang allows us to use their material for building a fun community. Since I will probably add the possibility for deep linking at some point, it's possible for any kind of builds to appear in the blueprint viewer. I want to make it clear that I do not condone unsuitable material.

Credits go to:

  • Mojang Studios for all game related material and data formats
  • The Minecraft Wiki for explanations of the formats, pregenerated block sprites and the layout for blueprint, which I blatantly stole
  • InventivetalentDev for the Minecraft Assets GitHub repository, which contains all the Minecraft textures and data extracted from the JAR shipped with the Java version
  • MediaWiki, for the Codex icon set

This site uses .nbt files and block sprites directly from GitHub and the Minecraft Wiki. This means I don't have to sync and duplicate all that content, and it's Mojang's property anyway.

Lastly, this project is work in progress, so expect everything to be broken.
